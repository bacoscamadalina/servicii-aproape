{% translate "Catalog și căutare" %}
{% translate "Afișăm date profesionale și informații despre firme din surse publice, inclusiv ONRC și Ministerul Finanțelor, pentru a documenta rezultatele locale. Căutările după județ, localitate și categorie sunt transmise prin adresa paginii." %}
{% translate "Revendicarea unei firme" %}
{% translate "Folosim numele, rolul, adresa profesională de e-mail, declarația și documentul justificativ pentru verificarea reprezentării, comunicarea deciziei și auditul acesteia. Documentul este privat, accesibil numai personalului autorizat și nu este publicat în catalog." %}
{% translate "Contul furnizorului" %}
{% translate "Folosim datele de autentificare și modificările profilului pentru a administra accesul, serviciile, acoperirea, portofoliul și publicarea controlată. Adresa profesională completă este opțională și apare public numai dacă furnizorul o completează, iar versiunea profilului este aprobată și activată." %}
{% translate "Solicitarea planului Partener" %}
{% translate "Furnizorul autentificat poate trimite un brief privat despre site-ul dorit și vede în cont starea discuției. Folosim obiectivul, calendarul, website-ul opțional, descrierea și notele operaționale numai pentru analiza solicitării și contactarea furnizorului. E-mailul intern de notificare nu include brief-ul sau datele contului." %}
{% translate "Sesizări publice" %}
{% translate "Formularul de sesizare nu solicită nume, e-mail sau telefon. Textul liber este păstrat pentru verificare; nu include în el date personale despre tine sau despre alte persoane." %}
{% translate "Solicitări către firme" %}
{% translate "Când soliciți o ofertă directă, trimitem firmei alese numele, e-mailul, telefonul și informațiile despre proiect pe care le introduci. Când alegi cererea comparată, aceleași date sunt transmise tuturor firmelor eligibile care au profil public, abonament activ și acoperire declarată pentru serviciul și localitatea selectate. Fiecare firmă vede numai propria conversație; tu ai un singur spațiu privat pentru comparație. Folosim datele pentru transmiterea solicitării, răspunsurile firmelor, urmărirea stării și prevenirea abuzului." %}
{% translate "Firmele pot propune în spațiul privat o dată și o oră pentru vizită, cu o notă scurtă. Confirmarea sau refuzul tău sunt vizibile numai firmei implicate; propunerea singură nu reprezintă o programare confirmată." %}
{% translate "Recenzii după colaborare" %}
{% translate "După acceptarea unei oferte poți trimite o singură evaluare. Cu acordul tău, publicăm după verificare nota, textul, prenumele și inițiala numelui; adresa de contact și detaliile solicitării rămân private." %}
{% translate "Statistici pentru firme" %}
{% translate "Numărăm vizualizările profilului și apăsările pe telefon, e-mail, website sau solicitarea de ofertă pentru a arăta firmei eficiența profilului. Nu stocăm adresa IP. Aceeași interacțiune este numărată cel mult o dată pe zi pentru o sesiune, folosind un identificator pseudonimizat care se schimbă zilnic." %}
{% translate "Securitate și funcționare" %}
{% translate "Procesăm informațiile tehnice strict necesare pentru sesiuni, protecția formularelor, prevenirea abuzului și investigarea incidentelor. Jurnalele operaționale sunt concepute să evite datele de cont neesențiale." %}

{% translate "Temeiul folosit depinde de flux: demersuri solicitate de tine și executarea relației cu furnizorul, obligații legale, consimțământ acolo unde îl cerem explicit și interesul legitim de a securiza și administra catalogul, după evaluarea impactului asupra persoanelor." %}
